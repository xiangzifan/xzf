# QASR v1 代码改动与复现说明

日期：2026-10-22

母版：远端 `main` 提交 `c787d56387b5268871dc4ef8e9ef7555dfc06040`

方法基础：A5-Delete + RESB-v1 M2 (`quality_diverse`)

新模式：`refiner_mode=qasr_full`

## 1. 修改边界

本版本不修改图像编码器、文本编码器、原有检索损失、噪声划分、RESB
入队/刷新/MMR 选择规则，也不改动 `mean`、`dua_pool`、`qdmp_mean` 和
`tugr_full` 的计算分支。修改集中在 RESB 选出 K 个支持样本之后的
GraphRefiner，以及把已存在于 Memory 的所选槽位元信息传给新模式。

历史 TUGR seed-42 的 Test Fusion rSum 为 498.9，低于同噪声历史 RESB-M2
的 502.1。其 DUA 权重仍接近均匀，且 QDMP 会把微弱 utility 标准化成固定
尺度。因此 QASR 不再使用 batch negatives 或样本内单位方差标准化。

## 2. QASR 的输入

对查询 i，RESB-M2 先选出 K 个配对支持槽位。目标模态特征记为

\[
\mathcal V_i=\{\mathbf v_{i1},\ldots,\mathbf v_{iK}\},
\qquad \mathbf v_{ij}\in\mathbb R^d.
\]

查询嵌入为 \(\mathbf q_i\)。每个所选 Memory 槽位还提供：

- 动量更新后的可靠度 \(\hat q_{ij}\in[0,1]\)；
- 最近刷新 epoch \(\ell_{ij}\)；
- 当前 epoch \(t\)。

新鲜度严格复用 RESB 的指数定义：

\[
f_{ij}=\exp\left(-\frac{\max(0,t-\ell_{ij})}{\tau_f}\right).
\]

`memory_bank.py` 只在 refiner 声明 `requires_support_metadata=True` 时传入
`support_quality` 和 `support_freshness`。旧 refiner 的调用签名和返回值不变。

## 3. 三路有界证据

### 3.1 当前查询相关性

\[
a_{ij}=\frac{1+\cos(\mathbf q_i,\mathbf v_{ij})}{2}\in[0,1].
\]

该项只比较当前查询和自己的支持集合，不使用 mini-batch 中的其他查询，
因此不会引入 batch false negatives。

### 3.2 支持集合共识

当 \(K>1\) 时：

\[
c_{ij}=\frac{1}{2}\left[
1+\frac{1}{K-1}\sum_{k\ne j}
\cos(\mathbf v_{ij},\mathbf v_{ik})
\right]\in[0,1].
\]

当 \(K=1\) 时定义 \(c_{i1}=1\)。该项降低孤立支持节点的证据。

### 3.3 Memory 可靠证据

\[
r_{ij}=\hat q_{ij}f_{ij}\in[0,1].
\]

最终证据为三个有界量的加权平均：

\[
s_{ij}=
\frac{w_q a_{ij}+w_c c_{ij}+w_m r_{ij}}
{w_q+w_c+w_m}.
\]

首轮冻结参数为

\[
(w_q,w_c,w_m)=(1.0,0.5,0.25).
\]

代码强制所有权重非负且总和大于零。默认对证据 `detach`，防止编码器通过
操纵路由分数形成捷径；支持节点经过消息投影和原型后的检索损失梯度仍完整。

## 4. 查询锚定的支持图传播

原 GraphRefiner 的多头支持自注意力 logits 记为

\[
L^{(h)}_{ijk}=\frac{(W_Q^{(h)}\mathbf v_{ij})^\top
(W_K^{(h)}\mathbf v_{ik})}{\sqrt{d_h}}.
\]

QASR 使用当前查询相关性的外积构造边先验：

\[
G_{ijk}=a_{ij}a_{ik}.
\]

传播权重为

\[
A^{(h)}_{ijk}=\operatorname{softmax}_k
\left(L^{(h)}_{ijk}+\lambda_gG_{ijk}\right),
\qquad \lambda_g=0.5.
\]

节点更新沿用可训练投影、残差和 LayerNorm：

\[
\mathbf h_{ij}=\operatorname{LN}\left(
\mathbf v_{ij}+W_O\sum_k A_{ijk}W_V\mathbf v_{ik}
\right).
\]

与 TUGR 的 sender-only 标准化 utility 偏置不同，QASR 的图先验有界且同时
依赖接收节点与发送节点和当前 query 的关系。

## 5. Sparsemax 与软 Adaptive-K

QASR 通过概率单纯形上的欧氏投影获得权重：

\[
\boldsymbol\alpha_i=
\operatorname{Sparsemax}\left(\frac{\mathbf s_i}{\tau_s}\right),
\qquad \tau_s=0.25.
\]

Sparsemax 满足

\[
\alpha_{ij}\ge0,\qquad\sum_j\alpha_{ij}=1,
\]

并允许 \(\alpha_{ij}=0\)。因此定义：

\[
K_i^{\mathrm{active}}=\sum_j\mathbb I(\alpha_{ij}>\varepsilon),
\qquad
K_i^{\mathrm{eff}}=\frac{1}{\sum_j\alpha_{ij}^2}.
\]

这同时给出确切激活数和连续有效 K，无需再训练独立整数 K 预测器。

## 6. 证据门控的安全残差

保留 legacy mean 原型：

\[
\mathbf p_i^{\mathrm{mean}}=\frac1K\sum_j\mathbf h_{ij},
\qquad
\mathbf p_i^{\mathrm{sel}}=\sum_j\alpha_{ij}\mathbf h_{ij}.
\]

归一化选择置信度为：

\[
z_i=1-\frac{\mathcal H(\boldsymbol\alpha_i)}{\log K}.
\]

Memory 置信度和最终纠正门为：

\[
\bar r_i=\frac1K\sum_j r_{ij},
\qquad g_i=\operatorname{clip}(\bar r_i z_i,0,1).
\]

输出：

\[
\mathbf p_i=\operatorname{Norm}\left[
\mathbf p_i^{\mathrm{mean}}+
\eta g_i(\mathbf p_i^{\mathrm{sel}}-\mathbf p_i^{\mathrm{mean}})
\right],\qquad \eta=1.
\]

当证据均匀时，\(\mathcal H=\log K\)、\(g_i=0\)，聚合严格退回 mean
prototype。单元测试使用对称支持集合核对了该数值等价性。

## 8. 首轮必须跑的两组

| 组别 | Memory | Refiner | 唯一方法差异 |
|---|---|---|---|
| C0 | `quality_diverse` | `mean` | 当前代码下的 legacy GraphRefiner |
| C1 | `quality_diverse` | `qasr_full` | 完整 QASR |

两组固定相同的 Flickr30K、60% 噪声文件、seed 42、batch 128、K=5、
5 warmup、20 co-training 和 40 epoch cosine horizon。不要复用 TUGR 的最佳
checkpoint，不要根据 Test 调参。

若只有一张 GPU，先启动 C0；其运行期间无需等待即可准备 C1。若有两张 GPU，
可在不同输出目录并行运行。两个启动脚本都会拒绝脏工作区和已有输出目录，
并在训练前执行源码编译与全部单元测试。

## 9. 结果解释边界

历史 RESB-M2 的 Test Fusion rSum 502.1 来自旧代码。当前代码把梯度裁剪范围
扩展到优化器的全部参数，因此 C0 是不可省略的同代码控制：

- C0 约为 501--502：TUGR 的下降主要来自其 GraphRefiner 机制；
- C0 约为 499：训练管线差异可能主导历史差值；
- C1 必须优先与同代码 C0 比较，而不是只和历史数值比较。

QASR 首轮仅是机制筛选，不宣称性能提升。建议至少达到 C1 相对 C0 的
Fusion rSum 增益 1.5，且 i2t/t2i R@1 无明显退化后，再做三 seed 与模块消融。

## 10. 诊断字段

每个方向都会记录：

- `pool_top1`、`pool_entropy`；
- `active_k`、`effective_k`、`pool_sum_error`；
- `message_entropy`；
- `qasr_score_mean/std`；
- `qasr_query_relevance_mean/std`；
- `qasr_consensus_mean/std`；
- `qasr_metadata_reliability_mean/std`；
- `qasr_correction_gate`。

需要重点检查：全部值有限、`pool_sum_error` 接近零、`active_k` 不长期固定为
1 或 5、correction gate 不长期接近零，以及两个检索方向是否表现一致。
